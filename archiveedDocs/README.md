Each snapshot includes the root README and complete docs tree as they existed
before the next update. v001 was assigned retrospectively to the existing set;
its original files were not modified to insert version labels.

Snapshots are historical records and must not be overwritten or edited. Links
between archived documents retain their original structure. Relative links to
application source may not resolve inside a snapshot because source code is not
archived here; consult the corresponding path in the current repository. An
archived document does not guarantee that current code still matches it.
